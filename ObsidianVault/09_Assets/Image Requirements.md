# Image Requirements

> **Status:** In Progress
> Specs so images look sharp and load fast.

## Formats
- Prefer **WebP** (or AVIF) for photos/screenshots; **SVG** for icons/logos.
- Provide PNG/JPG source where WebP isn't possible.

## Suggested Sizes
- Thumbnails: ~800×450 (16:9).
- Case-study hero: ~1600×900.
- Screenshots: native resolution, then optimized.

## Rules
- [ ] Always include descriptive `alt` text (accessibility).
- [ ] Optimize/compress before committing.
- [ ] Use consistent aspect ratios per context to avoid layout shift.
- [ ] No copyrighted third-party art → [[Placeholder Asset Rules]].
