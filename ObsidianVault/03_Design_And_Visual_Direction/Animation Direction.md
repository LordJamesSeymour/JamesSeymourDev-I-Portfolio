# Animation Direction

> **Status:** Not Started
> Motion should feel slick but never get in the way of content or performance.

## Principles
- Subtle, fast, purposeful (150–300ms typical).
- Respect `prefers-reduced-motion`.
- No janky scroll hijacking.

## Candidate Motion
- [ ] Hero entrance (fade/slide).
- [ ] Scroll-reveal for sections.
- [ ] Project card hover (lift / image zoom).
- [ ] Page transitions between home and case studies.

## Tooling Options
- [ ] CSS transitions/animations (lightest).
- [ ] Framer Motion (richer, adds dependency — needs approval).
