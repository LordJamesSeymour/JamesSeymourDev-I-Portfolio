# Responsive Design Notes

> **Status:** Not Started
> The site must work well on desktop, tablet, and mobile.

## Breakpoints (suggested)
- Mobile: `< 640px`
- Tablet: `640–1024px`
- Desktop: `> 1024px`

## Layout Behavior
- [ ] Projects grid: 1 col (mobile) → 2 (tablet) → 3+ (desktop).
- [ ] Nav collapses to a menu on mobile.
- [ ] Hero scales type and spacing down gracefully.
- [ ] Media (images/video) is fluid and never overflows.

## Testing
- [ ] Test on real phone + browser devtools device emulation.
- [ ] Check touch targets ≥ 44px.
